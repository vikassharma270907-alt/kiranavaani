Step 02

Gnani AI Prisma

Speech-to-Text (STT)
  • Receives the raw audio stream from client.
  • Recognizes mixed Hindi-English speech (Hinglish).
  • Produces clean text transcription.
  • Catalogue Keyterms: Injects domain vocabulary when configured.
STT Output Transcription
"bhaiya do packet maggi ek kilo sugar aur aadha litre milk bhej dena"
Speech Model Prisma v3.0 STT
Step 03

Order Parser

NLU & Entity Extractor
  • Processes transcription & strips fillers.
  • Identifies grocery entities, quantities & units.
  • Normalizes numerals: do → 2, aadha → 0.5.
Structured JSON Output
{ "items": [ { "product": "Maggi", "quantity": 2, "unit": "packets" }, { "product": "Sugar", "quantity": 1, "unit": "kg" }, { "product": "Milk", "quantity": 0.5, "unit": "litre" } ] }
In-House Rule / NLU Independent
Step 04

Catalogue Matcher

Fuzzy Matcher & Decision Gate
  • RapidFuzz matching vs 35-SKU catalogue.
  • Handles phonetic variants: meggi, chini.
  • Ambiguity scoring & confidence checks.
✔ High-Confidence Match Direct → Cart
⚠ Low / Ambiguous Match Clarification Loop
Clarification Prompt

RapidFuzz Engine Branching Loop

Shopping Cart

Order State Management
  • Adds matched SKU products, quantities & units.
  • Displays structured grocery cart in real time.
  • Allows customer confirmation or manual edits.
